## Required metrics (minimum — fill in specifics before Week 7)

Every service must expose at minimum:
- `http_requests_total` (counter, labeled by method + path + status)
- `http_request_duration_seconds` (histogram, labeled by method + path)
- `process_cpu_seconds_total` (from prom-client default)
- `process_resident_memory_bytes` (from prom-client default)

---

## Required log fields (from DOP-004 AC-03)

Every log line must be JSON with:
```json
{
  "timestamp": "ISO-8601",
  "level": "info|warn|error",
  "service": "user-service",
  "request_id": "uuid",
  "status_code": 200,
  "duration_ms": 42
}
```
